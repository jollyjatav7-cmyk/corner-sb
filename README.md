# 角球数据记录

边看比赛边记录两队的进入前场、进入禁区、传中、射门和角球，并即时预测半场角球的大小。按键的定义跟 StatsBomb 的事件数据一致，预测模型就是用这些数据建立的。

- 安装：用 Safari 打开这个仓库的 GitHub Pages 网址 →“分享”→“添加到主屏幕”，联网时打开一次即可离线使用。
- 记录：每队一块球场，在球场上点击发生的事件；点错了按“撤销”，或在“全部事件”里修改。按键的完整定义在“功能 → 按键定义”。
- 半场按钮（手机在最上面一行，iPad 在右上角）：上半场结束 → 下半场开球 → 全场结束。上半场的补时照常算在上半场（45+1、45+2…），按“下半场开球”计时从 45:00 开始，跟画面对得上。中场休息不用按暂停；上半场 44:00 以后暂停又按继续时，会问是下半场开球还是继续上半场。
- 底部快捷栏：同步（比分、角球、滚球盘口一次读取；连上了但还没开始记录时变成“加入”，按联网的时间、比分、角球中途加入）、更新盘口、我的注、撤销、功能。所有功能都在“功能”里按用途分组，每个功能附一句说明；看到“?”可以点开看这个功能是做什么的。
- 视频浮窗：一台手机边看画中画边记录时，在“功能 → 视频浮窗”选浮窗在屏幕上方或下方，app 会空出浮窗的位置，比分、盘口数据条、记录按键和快捷栏都排在浮窗外面。
- 预测：盘口面板显示本半场或全场角球超过盘口的概率、角球让球、最后角球数的分布和两队的攻势系数，可以调盘口、全场预期和补时。
- 盘口来源：联网自动（赛前 Bet365、比赛中 API-Football 的滚球盘），或“跟我的网站”：照你用的博彩网站填盘口，联网不会再改，底部按钮变成“填盘口”。
- 自动投注（模拟）：上半场盘到 40:00、全场盘和下半场盘到 85:00 自动结束（全场盘过了 40:00、中场休息都照常），已经记下的照常结算。要稳定多久可以选 1、2、3、5 分钟或“按赔率走势”（小和受让 1 分钟，大和让球 3 分钟，平手 2 分钟）；“记录满 5 分钟才开始”可以关掉。每场的投注明细（每一笔的时间、盘口、当时比分和角球、模型机会、结果，加上我的注）在自动投注页的“这场明细”、比赛仓库每场的“投注明细”，结算后提示里的“看明细”。
- 角球节奏：每队现在每 10 分钟几个角球＝基础节奏（时段、主客场、赛前预期）× 心态（比分、红牌）× 本场攻势（进入前场、禁区、传中），手机在数据条下方、iPad 在盘口面板最上方，一直更新；点开是详细的“拆开看”。
- 赛前预期：还没填时会自动填（开赛前连上联网、中途加入、开始记录时），也可以按“查／算”。博彩的赛前全场角球盘口（连上联网时自动读）定总数，本机有两队最近的比赛时再按两队场均分给两队；两队只有一两场资料也能用（往联赛平均靠），都没有时用联赛平均。联网的免费方案查不到以前的比赛，所以 app 每天自动收集五大联赛、日职联、沙特联、欧战和你连过联网的联赛的完场角球，存在设备上，你记录过、知道最后角球数的比赛也会放进去；日职联内置了 2026/27 赛季到 10/18 的比赛（来自 TotalCorner）。
- 让球的机会：模拟时加上“哪一队会占上风”的不确定性，让球的机会不会过于极端（回测：说 75% 的实际约 75%，以前约 72%）。
- 结束一场时可以选择“加入仓库”或“不加入，删除这场”；开始新比赛时，还没结束的比赛可以结束并加入、先留着或删除。
- 比赛仓库：搜索、筛选（已结束、未结束、待结算）、打开、补同步、结算、导出；同一场被拆成上半场、下半场两份时可以“合并上下半场”。“统计”有自动投注和我的投注的命中率、盈亏（填了赔率的）、模型检查（按联赛和主客队比较模型预计和实际角球）、各联赛平均角球；“备份与整理”可以导出全部、看储存空间、一次清掉几乎没有记录或忘了结束的比赛。
- 我的注可以填赔率（欧洲盘，只打数字也行：185 = 1.85，最近用过的和联网读到的赔率点一下就填好），显示至少要中几成才保本；盘口来自联网时，自动投注也会记下当时的赔率。
- 数据只存在设备上，可以导出成 JSON（附栏位说明），也可以直接传给 Claude 分析。

模型数据来源：[StatsBomb Open Data](https://github.com/statsbomb/open-data)（2015/16 英超、西甲、意甲、法甲共 1,517 场）。
